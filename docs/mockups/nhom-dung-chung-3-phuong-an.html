Slack User GroupsNhóm liệt kê ở Directories → User Groups; sửa người bằng “Edit Members”; menu ba chấm có “Edit group details” và “Deactivate group” kèm hỏi lại. → Xoá nhóm cất vào menu ⋯, có hỏi lại. Tài liệu
Linear TeamsThành viên quản ở Team settings → Members, thao tác qua menu ⋯ của đội. → Menu ⋯ trên thẻ nhóm. Tài liệu
